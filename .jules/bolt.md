## 2024-09-08 - O(n²) Anti-pattern in React Render Loops
**Learning:** Found an O(n²) performance bottleneck in `GlobalSearchDialog.tsx` where `.findIndex()` was being called on a potentially large `flattenedItems` array inside four `.map()` render loops (one for each item type). Since `flattenedItems` combines items from all categories, iterating through it for every single item rendered caused redundant operations, making the time complexity O(m * n) where m is the number of rendered items and n is the length of `flattenedItems`.
**Action:** Always watch out for array searching methods (like `findIndex`, `find`, `includes`) inside `.map` render loops. Instead, pre-calculate an index map using a `new Map()` combined with `useMemo` to achieve O(1) lookups during the render phase.
